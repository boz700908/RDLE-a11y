RDLE-a11y

Accessibility mod for the Rhythm Doctor level editor · 中文

What is this

A mod that makes the Rhythm Doctor level editor usable for visually impaired players. Provides full keyboard navigation and screen reader support.

Installation

  1. Download the latest release from Releases
  2. Extract, go into the main folder, select all and copy to the game directory (where rhythm doctor.exe is located)
  3. Launch the game

Requires Windows + Rhythm Doctor 1.0+. Standalone editor not supported. Beta branch recommended.
